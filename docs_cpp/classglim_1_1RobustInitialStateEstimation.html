Detailed Description

Robust initial state estimation. This class first performs odometry estimation using GICP frame-to-model registration with angular velocity-based pose prediction and deskewing. Then, it performs the IMU angular velocity bias estimation followed by the linear estimation of the gravity, velocity, and bias. Finally, optionally, it refines the estimation using nonlinear optimization (but we found it degrades the estimation, and thus turned it off).
